# Асинхронный ИИ-микросервис гаджет-консультанта (FastAPI)

Высокопроизводительный изолированный микросервис на базе FastAPI, разработанный для интеграции LLM-агента (ИИ-консультанта) в платформу e-commerce. 

🔗 **Живой пример интеграции в продакшене:** https://electronics24.store

Сервис асинхронно обрабатывает текстовые запросы пользователей, сопоставляет их с актуальным каталогом товаров и генерирует экспертные рекомендации на базе модели OpenAI через шлюз API без использования VPN.

## 🔧 Функциональность

- **Асинхронная архитектура**: Построен на FastAPI и `AsyncOpenAI` для параллельной неблокирующей обработки запросов к LLM.
- **Инженерный промпт-инжиниринг**: Реализует системные инструкции для удержания ИИ в роли продавца-консультанта электроники и предотвращения галлюцинаций (подбор строго из переданного каталога).
- **Валидация данных**: Входные пакеты данных и списки товаров валидируются на входе с помощью схем Pydantic v2.
- **Контейнеризация**: Упакован в Docker и поддерживает раздельные конфигурации сборки (`compose.yml` и `compose.prod.yml`) для локальной среды и продакшена.
- **Универсальность подключения**: Микросервис совместим с любыми OpenAI-совместимыми API-шлюзами и провайдерами.

## 🛠️ Стек технологий

- **Язык разработки**: Python 3.11
- **Веб-фреймворк**: FastAPI
- **ИИ-интеграция**: OpenAI SDK (асинхронный клиент `AsyncOpenAI`)
- **Валидация данных**: Pydantic v2
- **Инфраструктура**: Docker / Docker Compose / Переменные окружения (`python-dotenv`)

## 💻 Локальный запуск и разработка

Для развертывания и тестирования микросервиса в изолированном локальном окружении выполните следующие шаги:

1. Выберите папку, куда будете клонировать Git-репозиторий:
```bash
cd <имя_папки>
```

2. Клонируйте репозиторий:
```bash
git clone https://github.com/Oksana-Bachish/ai_consultant.git
```

3. Перейдите в директорию проекта:
```bash
cd ai_consultant
```

4. Создайте файл `.env.dev` в корневой директории проекта:
```env
AI_API_KEY=your_secret_api_key
AI_BASE_URL=https://your-provider.com
ALLOWED_ORIGINS=http://127.0.0.1:8000,http://localhost:8000
```

5. Запустите контейнер в изолированной сети командой:
```bash
docker compose up -d --build
```

После запуска Swagger-документация API будет доступна по адресу: `http://127.0.0.1:8001/docs`

## 🐳 Развертывание на сервере (Production)

На сервере (`CloudVPS`) микросервис разворачивается через конфигурационный файл `compose.prod.yml`. Он подключается напрямую к контейнеру интернет-магазина Django через изолированную внешнюю сеть Docker (`backend_app_net`). 

Это позволяет основному бэкенду Django выгружать товары из PostgreSQL и передавать их в FastAPI по внутренним именам контейнеров, не открывая порты микросервиса в публичный интернет.
